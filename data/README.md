# Data Directory

This folder holds the network traffic CSV files used for training and
analysis. **CSV files are not committed to version control** (see
`.gitignore`) because CIC-IDS2017 is several gigabytes.

## Option A -- Quick Start with Demo Data (no download required)

To try the full pipeline immediately without downloading anything:

```bash
python -m src.generate_demo_data
```

This creates `data/demo_traffic.csv` -- a small, **synthetic** dataset
shaped like CIC-IDS2017 (same column names and label style) so you can
install, train, and demo the dashboard end-to-end.

> ⚠️ **The demo dataset is randomly generated, not real network traffic.**
> Any accuracy/precision/recall numbers produced from it are for pipeline
> testing only and must not be reported as real IDS performance. Replace
> it with real CIC-IDS2017 data (Option B) before drawing conclusions or
> reporting results.

## Option B -- Real CIC-IDS2017 Dataset

1. Go to the official Canadian Institute for Cybersecurity dataset page:
   `https://www.unb.ca/cic/datasets/ids-2017.html`
2. Register/request access as instructed on the page and download the
   `MachineLearningCSV.zip` (or `GeneratedLabelledFlows.zip`) archive,
   which contains CSVs such as:
   - `Monday-WorkingHours.pcap_ISCX.csv`
   - `Tuesday-WorkingHours.pcap_ISCX.csv`
   - `Wednesday-workingHours.pcap_ISCX.csv`
   - `Thursday-WorkingHours-Morning-WebAttacks.pcap_ISCX.csv`
   - `Friday-WorkingHours-Afternoon-DDos.pcap_ISCX.csv`
   - `Friday-WorkingHours-Afternoon-PortScan.pcap_ISCX.csv`
   - ... (8 CSVs total, one per capture session)
3. Extract the CSVs into this `data/` folder (or a subfolder, e.g.
   `data/cicids2017/`).
4. Train against the real data:

```bash
# Single file
python -m src.train_model --data data/Monday-WorkingHours.pcap_ISCX.csv

# Or an entire directory of CSVs (all files are concatenated)
python -m src.train_model --data data/cicids2017/
```

## Expected CSV Format

Each CIC-IDS2017 CSV has ~78-85 columns of flow-level statistics
(duration, packet counts, byte counts, inter-arrival times, TCP flag
counts, etc.) plus a final `Label` column (e.g. `BENIGN`, `DoS Hulk`,
`PortScan`, `FTP-Patator`, ...). Column names sometimes have leading
whitespace (e.g. `' Destination Port'`) -- the preprocessing pipeline
(`src/data_preprocessing.py`) automatically strips and normalizes this,
and dynamically detects whichever columns are actually present, so a
partial/subset CSV still works.
